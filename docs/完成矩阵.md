## Gemini「任务/计划」模式（2026-10-29 补）

用户说的「计划模式」= 界面上的「**任务**」toggle。之前只有 `--writer task` 能切，`_use` 里没法发任务。

现在：

```bash
python src/scripts/gemini_use.py "用一句话介绍杭州" --task --tab 3
```

实测 `ok`，21.9s，reply=`杭州是一座融汇了西湖千年诗画底蕴与现代数字经济活力的"人间天堂"。`

### 这条路上修掉的两个真 bug

1. **任务模式的动作条不是同一排**：对话模式是 6 个图标（赞/踩/重生成/复制/更多/分享），
   任务模式只有 4 个（赞/踩/复制/更多）。`Site.actions` 原来只接受一张整排模板，
   匹配不到就退回「最左」，等于半盲点。
   现在 `actions` 支持多候选：`("gem_actions", "gem_actions_task")`，
   修复后 `pick.rule` 从 `leftmost` 变成 `actions_row`、模板 `gem_actions_task`、复制键 1.000。
2. **`--list` 会重置对话**：chatgpt 的 `--list` 原来顺手点一次「新聊天」，
   只为让模式按钮出现。读状态把用户正在聊的会话顶掉，这是错的。
   现在读操作一律不改页面；会话页读不到模式就返回 `unknown` 并说明，
   要读请用 `--new` 显式同意。

### 一个被推翻的判断

之前记过「点新对话会把模式重置回对话」——**实测是错的**。
点「发起新对话」后 `read_writer` 仍读到 `task`，截图也确认胶囊还在「任务」上。
所以 `--task` 里"先新对话再切模式"只是保守顺序，不是因为会被重置。

## chatgpt 的自动切换：安全停用（2026-10-29 16:20）

**原因是我按错了东西**：ChatGPT 输入框右侧那个橙色圆钮，空输入时是**录音键**，
有文字时是**发送键**。我把它当成"定位芯片的锚点"，用 `语音键中心 - 40px` 去点芯片，
偏移一错就直接按在录音上——实际发生了多次误触录音。

这不是调参能解决的：芯片右端离那个按钮只有 40~70px，窗口一改尺寸/位置就可能压上去。

所以 `chatgpt_choose` 的 `--model / --effort / --writer` **全部停用**，调用直接返回
`disabled_for_safety`，不点击、不抢焦点。

### 实测数据（16:35，当前窗口）

| 采样点 | 周围 40px 内的橙色像素 |
|---|---|
| 橙钮中心 | 1005 |
| **橙钮左 40px（我原来的芯片点击点）** | **500** |
| 橙钮左 120px | 59 |

这组数字说明：我原以为"芯片在按钮左边 40px"，实际那 40px 完全在按钮的判定区内。
连退到 120px 都还有 59 个橙色像素（芯片里有橙色图标）。

**结论**：用"橙色按钮 + 偏移"定位芯片这条路根本不通，必须改成"芯片文字/下拉箭头"
这类离按钮 200px 以上的锚点。

### 两个页面不一样（用户指出）

- **新聊天页**：顶部有「聊天/工作」、大输入框在页面中间、芯片在输入框右下
- **会话页**：没有「聊天/工作」、输入框在页面底部

脚本已加 `page_kind()`：不是新聊天页就直接退出，不拿首页的偏移去会话页点。

### 已加但未启用的防护

- `orange_near()` / `safe_click()`：点击前数目标 40px 内的橙色像素，>40 就拒绝点击；
- 所有点击点（芯片、模型入口、模型项、模式按钮）都已接上；
- 但 `main()` 仍是停用版，等锚点换成"离按钮 200px 以上"再开。

`chatgpt_use`（提问）不受影响：它点的是"输入文字后出现的发送键"，模板只在有文字时匹配。

## 明确停用的（gemini 思考等级）

**思考等级**：子菜单点一下就关（`click` 被当成 toggle），悬停不触发。
打不开，仍停用；调用返回 `not_supported`。

## 已知边界（不是 bug，是这套方案的代价）

- **换主题 / 换浏览器缩放 / 站点改版**：按钮类模板要重截；锚点类（输入框、"+"）
  抗得住（deepseek 换过窗口尺寸仍 1.000，已验证）。
- **窗口被挡住**：截图看不到 → 报 `composer_not_found`。脚本会自己提前台，但不新建/移动窗口。
- **长回答把动作条顶出视口**：报 `copy_not_found`，没有滚动兜底。
- **每个脚本只管当前激活的标签页**：用 `--tab N` 切。

## 运行时不调 AI

全部判据都是固定阈值：模板分数 ≥0.85、颜色 B−R>100、逐像素差 <12、勾区墨量 >5。
没有 API、没有 token、没有推理延迟。AI 只在开发期用过（挑模板、定阈值、看截图定位）。
