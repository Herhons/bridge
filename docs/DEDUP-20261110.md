# 为什么这轮没做 choose 去重（2026-11-10）

会审的四份意见里有三份把"桌面端 choose/use 去重"排在第一位。本文件记录核实结果：**方向对，但依据是错的，所以这轮不动代码。**

## 一、相似度的口径错了

`docs/ARCH-STATS.md` 的"重复代码"表算的是**同一端 choose ↔ use**，不是 choose ↔ choose：

| 比较 | quick_ratio | 同名函数 |
|---|---:|---:|
| `dsh_choose` / `dsh_use` | 0.94 | 35 |
| `codex_choose` / `codex_use` | 0.93 | 35 |
| `opencode_choose` / `opencode_use` | 0.91 | 42 |
| `dsh_choose` / `codex_choose` | 0.35 | 20 |
| `dsh_choose` / `opencode_choose` | 0.57 | 25 |
| `codex_choose` / `opencode_choose` | 0.21 | 20 |

会审把 0.91–0.94 当成"三个 choose 互相重复"，实际是"每个端的 choose 和它自己的 use 重复"。这个差别决定了抽取的边界完全不同。

## 二、真正逐对重复的是 13 个基座函数

`src/scripts/{codex,dsh,opencode}_choose.py` 各存一份：

`_init_dpi`、`idle_seconds`、`_pid_of`、`_proc_name`、`_windows`、`find_window`、`_win32_size_api`、`_raw_rect`、`_usable_rect`、`rect_of`、`place`、`activate`、`_record_receipt`（外加 `Desk` 类，dsh 与 opencode 之间相似度 0.94）。

合计约 500 行，全部是 Win32 取窗口 / DPI / 坐标 / 回执这些**没有业务语义**的部分。它们同时也被各自的 `use` 复制了一份——这也是 4 组 lockstep 测试存在的原因。

## 三、三套"菜单发现 / 读回 / 写回"不可能统一

| 环节 | dsh | codex | opencode |
|---|---|---|---|
| 认菜单 | 几何校准 + 行扫描 | 模板四件套 + 芯片几何 + 滑杆刻度 | 发送键锚点行 + UIA 芯片 + 白块面板 |
| 读回 | 模板打分，领先 ≥0.03 | 找勾 + 行距 ≤16px 归属 | UIA 精确名 + 邻接 ⌄ 校验 |
| 写强度 | 点第二行 → 点档位词 | 键盘逐步逼近 + 3 轮闭环纠偏 | 点第 2 个 ⌄ → 点行 |
| 认发送键 | 颜色筛选 | 位置兜底 + 黑/白图判失败 | 相对偏移 |

还有 12 处"看着一样、其实不同"的细节（`find` 默认阈值 codex 0.86 vs 0.90、点击节流 16/0.35 vs 14/0.4、`_printwindow` 的黑白图判据只有 codex 有、Esc 收尾次数不同……）。把这些统一，等于把每个端**能独立复核的实测坐标**变成共享分支里的隐式约定。

## 四、lockstep 测试是**有意**的约束

`tests/test_b17_dsh_lockstep.py`（20 个函数）、`tests/test_r3_choose_use_lockstep.py`（27 个）、`tests/test_r4_effort_floor.py`、`tests/test_b16_choose_foreground.py` 都断言 choose 与 use 的同名函数 **AST 逐字相等**。这不是遗漏，是"单文件契约"：每个脚本可以单独复制到别处、单独复核。

抽共享层就必然要把这些断言改掉。若将来真要抽，正确的做法是：

1. 只抽**无发送副作用**的 `choose`，`use` 不动；
2. 按 dsh → codex → opencode 逐对迁，每迁一对跑全量 + 真机一轮；
3. 测试从"AST 逐字相等"改成"两边解析到同一实现"（`dsh_choose.find_window is desk_win.find_window`）——这比文本相等更强，也更真实。

## 五、这轮实际做了什么

不做去重，改为把会审里**真能落地**的三条做完（见 `CHANGES_B21.md`）：gemini 二次发送、`lastreply` 竖排、`desk_sites` schema 测试，外加一条 pre-push 门禁。
