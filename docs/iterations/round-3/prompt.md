# Round 3 会审提问

附件 `material.md`：① 规格全文；② 当前账本/驱动实现与近两天修复；③ 四个待决问题。
只依据附件，不去仓库找文件。

## 输出格式（硬要求）

首行：`可访问=是` 或 `可访问=否`。
然后 **6 条意见**，按收益排序，每条五段：

```
§章节号 或 文件:行号
「附件里逐字抄出的一句」（只许一处「」，不许用它标你自己的话）
问题：…
失败：…
改：…
验收：没有真机时用什么离线测试
```

## 必须回答

1. **A 账本降级**：`accepted` 之后页面重置，记录永久拦住同一提问。给出「什么证据下允许降级、
   降成哪个状态、判定顺序如何避免误放一次重复发送」的具体规则。
2. **B 驱动适配器第一步**：`SiteDriver` 协议已定义但无人实现；39 个 qi 模块 + 20 个脚本有两套发送栈。
   第一步抽什么、不抽什么，怎么用静态检查防止出现第三套。
3. **C 孤儿锁**：`clear_stale()` 只在 iterate 的 review/summarize 调用。给出还要挂到哪些入口、
   以及清理失败时的语义（继续跑还是拒跑）。
4. **D 剪贴板事务**：paste 写剪贴板后无写后校验。给出最小实现，且不得破坏用户剪贴板。
5. **E/F 自由**：这两天的修复（动作条出视口、deepseek 锚点、grok 提问碎片化、上传绝对路径）
   最可能引入什么回归。
