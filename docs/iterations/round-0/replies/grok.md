1. 
§8 / §5.2
「网页端上传是循环的必备能力，须在 Round 0 修通，并有一次通过的自检验证」
问题：Round 0 同时要求用完整管道审本规格且必须证明上传可用。但上传自检依赖真机网页端，而建造阶段明确不强制真机一次跑完四席。若上传路径在 Round 0 前未稳定，则 Round 0 无法同时完成审规格与证明上传，循环卡在入口。
失败：编排器干跑通过后进入 Round 0，因上传未通而无法产出真读意见，停机条件 4 触发，Round 0 无法出口。
改：把上传自检通过列为 §5.1 进入条件的硬前置（用夹具或单席冒烟记录），Round 0 只负责用已通的上传路径跑完整管道，不再把修通和证明绑在同一轮。
验收：离线测试断言 upload 配置且自检未通过时拒绝开 Round 0；干跑用已标记通过的上传夹具能产出 quote_check。
2. 
§5.3
「真读 = 命中 ≥ 3 且命中率 ≥ 0.7，且至少一条落在 docs/self_iteration_spec.md」
问题：规格审与代码审共用同一数值阈值。规格文本短、章节少，5–8 条意见很容易因只引了 2 个章节被判未读，即使内容完全命中。§9.1 又允许章节号或行号对上快照文本算命中，与 ≥3 冲突。
失败：四家都认真审了规格，却因阈值过高全部 partial/未读，汇总空转，停机条件 1 误触发。
改：Round 0 单独阈值（例如命中 ≥2 且命中率 ≥0.6，且至少一条落在本规格），并在 quote_check.py 用测试锁死规格核心路径与代码核心路径两套规则。
验收：用 2026-11-11 夹具 + 本规格夹具分别断言真读/未读判定；空白归一测试覆盖章节号+引句。
3. 
§10 / §5.4
「若意见要求改变轮次合同（阶段、闸门、停机条件、评审厂商集合、匿名规则、授权边界），属于大改，必须先得到 Herhons 点头」
问题：Round 0 的目的就是审本规格并可能修订合同条款，但闸门把改合同一律列为大改。编排器在 Round 0 产出计划后必须停等人工，无法在同一轮内完成修订规格 + 同步编排器的闭环。
失败：幸存意见要求微调停机条件或四审集合，流程卡在大改待批，无法归档 CONTINUE，Round 0 出口条件无法满足。
改：明确 Round 0 内对规格文本的修订（含合同条款澄清）默认小改，除非触碰 PLAN.md 红线或 known_gaps.md 已决定不做项；真正的合同大改才走 §10 大改定义。
验收：干跑夹具中含改停机条件措辞的意见，断言计划分类为小改且允许继续；含改四审厂商集合的意见仍判大改。
4. 
§12 / §7.3
「会审齐了，验真后没有任何「真读」幸存意见……即停」
问题：Round 0 是第一次真机跑完整管道，上传/粘贴、网页端稳定性、引用格式都可能不稳定。一次失败即停，没有 Round 0 允许重试一次的明确出口，与 §5.5 最多再跑一轮 Round 0 的意图不一致。
失败：某家因网页端临时不可用未达真读，三家凑不齐，直接 STOP，无法进入 §5.5 的 round-0b。
改：停机条件 1 对 Round 0 例外——未达 3 家真读时允许按 §5.5 开 round-0b（须 Herhons 点头），两次后才强制停。
验收：状态机测试：Round 0 真读不足时写 CONTINUE 到 round-0b；第二次仍不足才写 STOP。
5. 
§9.2 / §2
「匿名包必须做到：去掉厂商名、模型名」
问题：汇总者是 Gemini，而四审里也有 Gemini。即使去掉名字，Gemini 仍可能识别出自己上一轮的措辞或结构，产生自我回声。规格未规定汇总 Gemini 不得与四审 Gemini 同会话/同窗口。
失败：匿名包里仍保留 Gemini 特有的引用风格，汇总者偏袒或重复自己的意见，优先级失真。
改：要求汇总必须用新对话，并在匿名包增加禁止根据措辞猜测来源的硬指令；归档记录会话 ID 证明隔离。
验收：匿名化测试断言输出无厂商名；干跑断言汇总 prompt 含新对话标记且不携带历史。
6. 
§4 / §13
「状态机落盘。进程被杀后能从本轮已完成的步骤续跑，且不违反防重发」
问题：规格要求续跑，但未定义已 accepted 的提问在状态机中的持久化格式，也未说明与现有 live_job / 账本的对接边界。建造时容易重新实现一套发送状态，违反不要再复制一套发送栈。
失败：续跑时重复发送已 accepted 的提问，或状态机与账本不一致，触发防重发红线。
改：明确状态机只记录步骤完成标记 + 已 accepted 的 job id，发送语义完全复用现有 live_job；补充状态文件 schema 与恢复测试。
验收：杀进程后从中间步骤恢复的离线测试，断言同一提问不再发送且 quote_check 能续跑。
